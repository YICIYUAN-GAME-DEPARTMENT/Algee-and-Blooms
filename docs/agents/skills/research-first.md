# Skill: 外部资料调研与许可证（research-first）

**描述：** 引入外部代码 / Godot 插件 / 美术 / 音频 / 字体 / 第三方方案，或对 Godot 4.7 API 与实现路线不确定时，先做资料调研、许可证判定与方案提案，用户确认后再落地。

> 本技能是轻量执行手册，不替代人类决策。常规功能开发（已有权威章节与现成实现）不需要走本流程；但**外部依赖、外部素材、未确认的新架构 / 算法**必须先调研。

## 使用场景

- 引入第三方库、Godot 插件、代码片段、Shader
- 替换或新增 CC0 / 开源美术、音频、字体
- 采用规划稿中的新能力（生成器、求解器、原生扩展、算法核心）
- 对 Godot 4.7 API、TileMap / Terrain、导出行为不确定
- 需要判断许可证、商用、修改与再分发权限

## 执行步骤

### 1. 明确检索目标

把需求拆成可检索的问题，至少覆盖：

- **API / 节点 / 资源**：Godot 4.7 中对应类、方法、信号、生命周期是什么？
- **推荐做法**：官方推荐与社区常见做法分别是什么？差异与坑在哪？
- **可运行案例**：有没有 Godot 4.x + GDScript 的网格 / TileMap / UI 示例？
- **版本适配**：是否依赖 Godot 3.x、旧 GDScript API 或已废弃节点？
- **资产 / 插件许可**：许可证是什么？能否修改、再分发、商用？

### 2. 检索与核对

- 优先官方文档、源码与 release 说明；必要时用 WebSearch / WebFetch / GitHub MCP。
- 同时覆盖中英文关键词；确认页面版本是 **4.7 / stable**。
- 核对仓库最近提交、archived 状态、issue 活跃度。
- **禁止用记忆替代检索**；搜索结果摘要只作线索，关键结论打开原文核对。

### 3. 许可证判定

按顺序查：`LICENSE` / `COPYING` / `NOTICE` → README 的 License 段（仅线索）→ Asset Library / 包管理器元数据 → 子目录与素材独立许可 → 传递依赖。

| 问题 | 结论 |
| ---- | ---- |
| 许可证是否明确？ | 否 → 按无许可处理，只能学习后复现或放弃 |
| 是否要求衍生作品开源？ | 强 copyleft → 不直接依赖；弱 copyleft → 优先独立依赖 |
| 是否允许修改与再分发？ | 否 → 不采用 |

确定运用方式：**A 原样依赖 / B 修改后使用 / C 学习后独立复现 / D 不采用**。

### 4. 形成方案

至少给出 1 个推荐方案；存在多条路线时列对比。每个方案写清：

- 来源、版本、访问日期
- 许可证与运用方式（A/B/C/D）
- 与 Godot 4.7 / GDScript 的兼容性
- 对现有模块、场景、数据配置的影响
- 风险：维护停滞、API 变更、性能、许可证、与项目规范冲突

### 5. 输出提案并停下

在对话中输出提案，**等待用户明确确认**后再编辑代码 / 场景 / 资源。有效确认如“确认方案 1”“采用方案 2”；沉默或“好的”不算确认。

### 6. 实现与交付

按确认方案执行；偏离方案时先说明原因并重新确认。交付摘要附「资料依据与许可证」：来源、链接、版本、许可证、运用方式；无外部引用时写“未引用外部资料”。

## 项目红线

- 不引入 **C# / 第三方插件 / 原生扩展**，除非人类明确同意并同步权威文档（2026-11-24 已确认 C# 规则与算法单一权威、GUT 9.7.1；新增其他依赖仍按本流程）。
- 不直接使用无许可证或来源不明的素材；CC0 / 开源素材登记来源与许可证。
- 外部大资源走 Git LFS，并在开发文档 §3.9 登记 A-xx。
- 不整段复制外部代码进项目；优先学习后按本项目规范复现。
- 不擅自把规划稿中的架构 / 算法直接落地；先确认，再同步权威文档。
- 改动玩法 / 数值仍需遵守 `AGENTS.md` §5.1：先问人类，再改文档与 `Balance.tres`。

## 常见坑

- Godot 3.x 教程 / 示例不能直接用于 4.7，API、导出属性与信号写法差异大。
- README 写 MIT 但没有 `LICENSE` 文件 → 按无许可处理。
- 只查代码许可，忽略字体、音频、贴图的独立授权。
- 忘记记录访问日期 / 版本，后续无法回溯。
- 把“学习后复现”当成“可以直接搬代码”。
- 外部工具重存 `.tres` 可能丢失 `uid` 头，导致场景引用失联（见 `godot-tooling`）。

## 输出格式

- 调研问题与结论
- 候选方案对比（来源 / 许可证 / 运用方式 / 兼容性 / 影响 / 风险）
- 推荐方案与待确认项
- 实现后交付摘要中的「资料依据与许可证」
