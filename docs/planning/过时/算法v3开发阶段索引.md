## 2. 范围与共同约束

### 2.1 本期范围

- 生成：模板 + 机关优先 + 自由模式混合；
- 评分：交互项 + 最小前瞻 `H` + 基线扣除 + 单调校准；
- 数据：局内盲评、地图与特征记录、离线标定；
- 表现：局内解法提示（动态变色 + 透明度热衰减）；
- 工程：确定性、复杂度预算、失败降级、文档同步。

### 2.2 共同约束

- **不改规则 / 数值**：移动、截断、生长、胜负仍以功能需求 §4 为准；
- **确定性**：同一 `seed + tier + generator_version` 输出一致；
- **复杂度指标**：只写 `O(...)` / 参数化复杂度 / 状态数，不以毫秒为设计指标；
- **无外部依赖**：不引入 NuGet / 运行时训练 / 神经网络；
- **失败降级**：自由 → 模板 → RouteFirst，绝不崩溃；
- **规划稿**：本文与子文档不写入权威文档，规则性变更需人类确认。

### 加载流程与生成进度（2026-11-26）

- **异步加载**：`GameManager.start_generated_level` 不再同步生成，先切 `Scenes/UI/LoadingScreen.tscn`；加载屏用 `GenerationService.Begin / Advance / ProgressJson` 分帧推进（每帧约 8ms），成功后 `apply_generated_result` 进入关卡。
- **加载屏内容**：进度条 + 百分比 + 当前阶段（地形 / 机关场 / 选 S-E / 精确验证 / 公平性 / 评分）+ 尝试次数；「点亮花瓣」小游戏打发等待；失败按 `seed+1 … seed+5` 重试，仍失败回主菜单。
- **即时信息**：关卡 HUD 立即显示实际生成结果（`模板机关 Tn` / `经典路线（模板降级）`），降级用暖色标注；不再只在通关评分卡里出现。
- **预算与降级策略**：`loading` 总预算 90s / 3000 工作单元 / 8 候选 / 64 次搜索（模板模式取 6 候选）；**单次构建尝试限时 50ms**（background 20ms / prefetch 15ms / bootstrap 300ms）。分帧模式每次 `Advance` 只推进一次尝试，保证两次尝试之间必有渲染帧；求解、S-E 枚举、机关布点、指标搜索在安全点协作让出。降级候选**不进入 MAP-Elites**，仅在没有模板候选时兜底，避免难关被降级关顶替。实测 hard 单次尝试 ≤ 51ms。
- **负机关阶段（2026-11-26）**：机关初始阶段允许 −10 – cap；负值不占格、只把核心染蓝（越负越深），每周期仍 +1。模板（T3–T8 的 `MinInitial`）与 `ParamSampler` 会使用负起始阶段，增加难度梯度的状态数（权威口径见功能需求 §4.2.5 / §7）。
- **结构生成（2026-11-26）**：`PairSelector` 改为「静态路径定花瓣 → `ExactBfsSolver` 取时间规则下的真实路线 → 按岔路 / 截断 / 威胁 / 目标步数排序」；并在路径旁**雕刻死路**、放唯一花瓣，强制"进去再踩身体出来"。headless 59 个模板关：**51 个带截断（回路）、59 个带 ≥2 步岔路**。感知危险场仍只用于公平性校验（K=6 / η=0.35，约 2–3 格衰减），不是结构瓶颈。
- **档位显示**：HUD 在实测档与请求档不一致时追加「请求X」；`_score_floor` 对齐 `BranchScoreSchemes` 阈值（Easy<35 / Normal<48 / Hard<60）。

## 4. 依赖关系

```text
M1 模型底座
 ├─→ M2 模板 + 机关优先
 │    └─→ M3 自由生成 + 混合
 │         └─→ M7 数据采集 + 标定
 ├─→ M4 评分 v3 + 校准
 │    └─→ M5 评分训练集 UI
 │         └─→ M7
 └─→ M6 解法提示（可并行）
```

**建议顺序：**

1. M1 → M2，先把“机关优先 + 模板”跑通；
2. M4 与 M2 并行，用现有 RouteFirst 关卡先验证评分口径；
3. M5 在 M4 后接入，尽早开始积累标签；
4. M3 在 M2 后接入自由模式；
5. M6 可随时并行；
6. M7 在 M3 + M4 + M5 后启动。

## 5. 阶段验收门

| 门 | 条件 |
| --- | --- |
| G1（M1 后） | R1 表与 `RuleState` 一致；L1–L5 可测；无 warning/error |

| G6（M6 后） | 提示在 L1–L5 + 随机关卡可用；不影响玩法 |
| G7（M7 后） | 200+ 条评分；留出集 Spearman 不低于基线；高分段可校准 |
