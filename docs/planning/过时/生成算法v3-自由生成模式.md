## 0. 摘要

模板模式保证命中率与难度先验，但长期只出模板会让关卡结构趋同、训练集失去多样性。v3 增加**周期性自由生成模式**：

- 不依赖模板，直接采样机关场；
- 仍然保持“机关优先 → 选 S/E → 公平性 → R2 验证”的顺序；
- 与模板模式共用同一套 `PairSelector`、`FairnessEvaluator`、`ExactBfsSolver` 与评分；
- 每次生成在结果与评分记录中写入 `generation_mode = "template" | "free"`，用于后续分析“模板是否过拟合”。

**一句话：** 模板负责稳定产出，自由模式负责探索与去模板化；两者按确定性比例混合，所有结果都进入同一训练集。

---

## 1. 目标与非目标

| 目标 | 非目标 |
| --- | --- |
| 周期性生成非模板关卡，打破模板单一化 | 用自由模式替代模板主路径 |
| 记录 `generation_mode` 与自由场参数 | 改变规则 / 数值 / 机关形状 |
| 让训练集能比较“模板 vs 自由”的体感差异 | 引入外部依赖或运行时训练 |
| 保持 R2 可赢、公平性与目标步数约束 | 保证自由模式一定成功 |

---

## 2. 与模板模式的差异

| 维度 | 模板模式 | 自由模式 |
| --- | --- | --- |
| 场种子 | `TemplateLibrary` 实例化 | `FreeFieldSampler` 直接采样 |
| 结构先验 | 有（T0–T8） | 无 |
| 目标函数 | `TemplatePrior + 交互项` | `Novelty + 交互项` |
| 命中率 | 高 | 较低 |
| 多样性 | 受模板限制 | 高 |
| 记录 | `template_id` | `template_id="free"` + `free_field_params` |
| 失败降级 | 自由模式 → 模板模式 | 自由模式 → 模板模式 → RouteFirst |

两种模式都遵守：

- 机关优先：先定机关场，再选 S/E；
- 允许机关压规范路线；
- 公平性 AUC / 模糊隶属度硬约束；
- R2 精确验证；
- 评分由拟合函数输出。

## 3. 自由场生成规范

### 3.1 参数分布

自由模式从以下分布采样，不引用任何模板：

| 参数 | 分布 | 约束 |
| --- | --- | --- |
| 机关数量 `m` | `1–3` | 与权威建议一致 |
| 机关最高阶段 `cap` | `1–4` | 不超权威上限 |
| 生长周期 `I` | `4–8` | 由 `Balance` 约束 |
| 初始阶段 `a_i` | `Uniform(0..cap)` 或 `{0, cap/2, cap}` | 允许错峰满级 |
| 中心分布 | Poisson 簇 / 蓝噪声 / 地板随机 | 不穿墙、不占 S/E |
| 障碍密度 | 沿用 `ObstacleModels` | 与模板模式一致 |

**初始阶段策略：** 至少一次生成使用“错峰”集合（例如 `{0, 1, cap}`），避免所有机关同时满级；这是自由模式制造顺序压力的主要手段。

### 3.2 场验收

自由场在进入 S/E 选择前必须通过：

- `R1` 可行核非空；
- 至少存在一个 S/E 对，使 R1 路线长度落在目标带；
- 在该对中存在至少一次**机关诱导的可行分支变化**（否则是纯装饰场）；
- 公平性预检（可选，快速版）：AUC 不低于阈值太多，避免整批浪费；
- 机关不全在可行走廊之外（平凡场直接丢弃）。

失败 → 重新采样自由场；连续失败 → 模板模式。

### 3.3 S/E 选择与新颖度

- 使用与模板模式相同的 `PairSelector`；
- 目标函数去掉 `TemplatePrior`，加入 `Novelty`：

```text
J_free = 0.35·H_norm + 0.20·Deception + 0.15·Cuts
       + 0.15·Contention + 0.10·L_tight + 0.05·Novelty
```

- `Novelty` 的行为描述符：

```text
(generation_mode, m, I, cap, H, cuts, contention, fairness_auc, size)
```

- `Novelty` = 与 MAP-Elites 存档中最近格的距离；优先填充空/稀疏格；
- 不把 `template_id` 作为自由模式的描述符（它固定为 `free`）。

### 3.4 混合策略

建议按档位设置自由概率 `p_free`：

| 档位 | `p_free` 初值 |
| --- | --- |
| easy | 0.10 |
| normal | 0.15 |
| hard | 0.25 |
| expert | 0.30 |

- 确定性调度：`hash(seed, level_index) % 100 < p_free × 100`；同一 seed 结果可复现。
- 保底：每 5 个生成关卡至少 1 个自由模式（仅在生成成功时计数）。
- 降级链：

```text
free 失败 → template 重试 → RouteFirst 降级
```

- 记录降级原因：`free_field_rejected`、`no_pair`、`unfair`、`unsolvable`、`fallback`。

## 4. 记录字段

评分记录（见 [评分训练集与标定规范](评分训练集与标定规范.md)）必须包含：

```json
{
  "generation_mode": "free",
  "template_id": "free",
  "free_field_params": {
    "m": 2,
    "cap": 3,
    "growth_interval": 6,
    "initial_levels": [0, 2],
    "center_distribution": "poisson",
    "obstacle_model": "noise_cluster"
  },
  "novelty": 0.37,
  "archive_cell": [2, 4, 1, 2]
}
```

- 模板模式：`generation_mode="template"`，`template_id="T4_multi_gate_counter"`，`free_field_params=null`；
- 自由模式：`generation_mode="free"`，`template_id="free"`，`free_field_params` 保留完整采样参数；
- 降级模式：额外记录 `fallback_from`、`fallback_reason`。

**用途：**

- 比较模板 / 自由的体感分差异；
- 检查某些模板是否被系统性高估或低估；
- 检查自由模式是否只是“换皮模板”；
- 为后续模板库扩展提供候选结构。

## 5. 复杂度

| 步骤 | 复杂度 | 说明 |
| --- | --- | --- |
| 自由场采样 | `O(V + m·V)` | 中心分布 + 去重 |
| 场验收（R1） | `O(F·V·T)` | 与模板模式一致 |
| S/E 选择 | `O(|S|·|E|·F·V·T + K·3^L·2^F)` | 与模板模式一致 |
| 新颖度 | `O(archive_size)` | 行为描述符距离 |
| 记录 | `O(1)` | JSONL 追加 |

自由模式命中率低于模板模式，因此预算应优先给“场验收”和“Top-K 验证”，不要在每个自由场上跑完整评分。

## 6. 清单

### 6.1 实现清单

- [ ] `FreeFieldSampler`：`m / cap / I / initial_levels / center_distribution` 采样
- [ ] 自由场验收：R1 可行核、目标步数、非平凡割、公平性预检
- [ ] `PairSelector` 支持无模板先验 + `Novelty`
- [ ] 混合调度：`p_free(tier)` + 确定性 hash + 每 5 关保底
- [ ] 降级链：free → template → RouteFirst
- [ ] `generation_mode` / `template_id="free"` / `free_field_params` / `novelty` 写入 `Candidate`、`GenerationResult`、评分记录
- [ ] MAP-Elites 行为描述符加入 `generation_mode`
- [ ] HUD / 调试信息显示当前模式（可选，评分前隐藏）

### 6.2 测试清单

- [ ] 同 seed 的自由场采样完全一致
- [ ] `generation_mode` 与 `template_id` 在所有路径上正确写入
- [ ] `p_free` 统计符合目标（1000 次生成的比例）
- [ ] 自由场失败时降级链正确，不崩溃
- [ ] 自由模式关卡仍满足 R2 可赢、公平性、目标步数
- [ ] 模板模式与自由模式在同一评分口径下可比较

### 6.3 验收清单

- [ ] 连续 20 关至少出现 3–4 个自由模式关卡（按档位）
- [ ] 自由模式关卡没有明显的“纯随机 / 不可读”结构
- [ ] 训练记录中能区分模板 / 自由，且能按模式分组统计
- [ ] 不改变任何权威规则与数值

## 7. 风险

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 自由模式不可解率高 | 浪费预算 | 场验收 + 降级链 |
| 自由模式出现“纯随机不可读” | 体感差、评分噪声 | 公平性 + 非平凡割约束 + 模板降级 |
| 自由模式与模板难以比较 | 训练集偏差 | 固定评分口径；记录 `generation_mode`；分层统计 |
| 新颖度压过质量 | 出怪图 | `Novelty` 权重 ≤0.05；硬约束优先 |
| 模板被长期冷落 | 模板库退化 | 保底模板比例；MAP-Elites 保留模板格 |
| 确定性被破坏 | 同 seed 不一致 | hash 调度；固定采样顺序 |
